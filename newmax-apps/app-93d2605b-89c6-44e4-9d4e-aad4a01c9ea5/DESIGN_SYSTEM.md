# Design System

## Product-Specific Design Direction

- 使用者：聊天时扫一眼自选，需要时在停靠面板调整名单，在窗口拉取现价的人。
- 主路径：窗口输入代码并拉到真实报价 → 信息卡用指标卡显示前 3 只 → 停靠面板置顶或移除。面板里的添加会尝试拉取；被隔离时说明去窗口，不写假价格。
- 视觉方向：三处都用 macOS 股市小组件的行情行，不再用新闻纸刊头或指标块。一行是代码、名称、分时面积、现价和带正负号的涨跌。涨为红、跌为绿，方向同时用三角和正负号表示。窗口和停靠面板是这行的管理页，信息卡是同一行的前 3 只。
- 布局：窗口是紧凑标题、限宽添加栏、可滚动行情行，结果占主要高度。停靠面板从 240px 起可用：精简顶部状态栏（同步状态+数量、Ghost 刷新图标按钮）、一体化搜索栏（输入后在框内右侧出现清空与添加按钮，无输入时不占空间，带浮动联想卡片）、可滚动分组卡片列表（分为「信息卡 · 前3只」与「其余关注」）；宿主已画出标题，页内不再重复应用名。信息卡 252×160，透明根节点，最多 3 行。
- 字体：系统中文黑体，价格 tabular-nums。不加载远程字体，不用宋体刊名。
- 间距：4 / 8 / 12。面板内边距 12px（窄屏 10px），分组卡片内边距与圆角 12px，窗口 16–20px。信息卡根节点零内边距。分时与现价之间留约 10–24px，面板内趋势图占约 1.15fr 比例，自适应拉伸保持清晰。分时填充从线下 0.5 不透明度沿曲线缓出到全透明，灰底上仍能看见，不用一条直线浓色块。
- 颜色：窗口和停靠面板浅色底 `#f5f5f7`、卡片底 `#ffffff`、深色底 `#1c1c1e`、深色卡片 `#2c2c2e`。浅色跌 `#1f8a3d`、涨 `#d70015`；深色跌 `#30d158`、涨 `#ff453a`。涨跌幅在侧栏面板采用带柔和红/绿底色的胶囊徽章（配三角与正负号），提升扫视效率。主按钮用墨色填充，不是铜色。文字跟随 `prefers-color-scheme`。信息卡外壳背景和边框都是透明，不另铺灰底，行情行直接落在信息面板上。
- 组件：面板顶部刷新为 Ghost 图标按钮；添加按钮仅在输入关键词后内嵌显示在搜索框右侧。行情行本身即为可拖拽排序区域（hover 显示 `grab` 手势，聚焦后支持上下方向键移动），不再显示常驻拖动手柄或常驻删除按钮；行右上角在 hover/聚焦时浮现「更多（`...`）」按钮，点击展开菜单（置顶到首位、查看/收起详情、移除——移除需二次确认）。点击股票行可展开轻量详情条。焦点为 2px 系统蓝描边。状态是圆点加时间：3 分钟内为绿色「刚刚刷新」，更久为琥珀色时间。隔离或缓存提示可手动收起。
- 状态：空列表给出下一步；刷新中按钮变为「正在刷新」并禁用重复提交；失败保留上次价格并写明可再试；查不到的代码停在输入框错误里。
- 窗口：宿主默认约 1100×760，最小 760×520。窄于 860px 时藏起区间列。
- 停靠面板：默认 420px，必须在 240px 下不横溢。输入在窄宽度下改为上下排列。
- 信息卡：不写应用名，也不再画指标块。宿主卡片 `variant` 为 `flat`，浅色和深色的背景、边框都设为 `transparent`，页面根节点也不再画第二层底或边框。每行是代码、名称、分时、现价、带正负号的涨跌。名称省略，完整内容在 title 里。有行情时不另占一行写刷新时间。

## Product Feel

- 打开面板就能看到已保存的报价和置顶、移除，不是介绍页。
- 数字对齐，方便比较。
- 不把未拉取的价格画成示例行情。

## UI Rules

- 信息卡、停靠面板和窗口都用同一套行情行，不再套指标块，也不再用刊头表格。
- 移除必须再点一次「确认移除」。
- 面板和信息卡不能假装自己已连上行情网站；拉不到时写明打开窗口。
